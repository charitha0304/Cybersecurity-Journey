# Learning Resources

Resources I am actively using in this transition. This is a working list, not a comprehensive
catalogue — entries are added as I use them.

---

## PortSwigger Web Security Academy

Primary lab environment. Free, browser-based, and organised by vulnerability class rather than
by tool. Each topic pairs written material with hands-on labs against deliberately vulnerable
applications.

Used for:
- Structured coverage of web vulnerability classes
- Hands-on labs documented under `labs/`, with tool-practice notes under `fundamentals/`
- Reference material on individual vulnerability classes

---

## Burp Suite Documentation

Official PortSwigger documentation for Burp Suite.

Used for:
- Installation and browser/proxy configuration
- Intercepting HTTP traffic
- Modifying and reissuing requests
- Target scope configuration

---

## TryHackMe

Guided, beginner-oriented rooms covering web and networking fundamentals.

Used for:
- Web fundamentals — HTTP/HTTPS, requests and responses, headers, cookies, status codes
- Foundational concepts before moving to unguided lab work

---

## OWASP

Open Worldwide Application Security Project. Vendor-neutral reference material for application
security.

Resources I intend to work through:
- **OWASP Top 10** — the standard reference for common web application risks
- **OWASP API Security Top 10** — the equivalent for APIs
- **OWASP Cheat Sheet Series** — concise remediation guidance by topic
- **OWASP Web Security Testing Guide (WSTG)** — testing methodology
- **OWASP Application Security Verification Standard (ASVS)** — requirements framework for
  assessing application security controls
- **OWASP Juice Shop** — deliberately vulnerable application for practice
